# AI录音助手 - 需求文档 v1.0

## 项目概述
一个跨平台AI录音助手，支持实时语音转文字、AI文本理解与处理。

**目标平台演进**：Windows桌面 → Mac → 移动端(iOS/Android) → 网页版

---

## 核心功能需求

### 1. 音频录制与管理
- [x] 实时音频录制（麦克风输入）
- [x] 录音暂停/恢复/停止
- [x] 录音时长显示
- [x] 录音文件本地保存
- [x] 录音列表管理（查看、删除、重新播放）

### 2. AI语音识别（Speech-to-Text）
- [x] 支持将录音转换为文本
- [x] 实时显示识别结果
- [x] 支持多语言识别（中文/英文优先）
- [x] 识别结果编辑修正

### 3. AI文本处理
- [x] 文本摘要生成
- [x] 关键词提取
- [x] 内容分类/标签
- [x] 可扩展AI功能（prompt定制）

### 4. 数据管理
- [x] 本地数据库存储（录音记录、文本、AI结果）
- [x] 导出功能（TXT/MD/JSON）
- [x] 搜索功能（按日期、内容、标签）

### 5. 用户界面
- [x] 简洁的录音控制面板
- [x] 实时转录显示区域
- [x] 录音历史列表
- [x] 设置面板（API配置、语言选择等）

## 技术栈选择

### 前端
- **框架**：Electron（跨平台桌面应用）
- **UI框架**：React + TypeScript
- **样式**：Tailwind CSS
- **状态管理**：Zustand

### 后端
- **语言**：Python 3.10+
- **框架**：FastAPI（轻量级，支持异步）
- **任务队列**：Celery（异步处理）

### 数据存储
- **数据库**：SQLite（本地，无需额外部署）
- **ORM**：SQLAlchemy

### AI API（初期免费方案）
| 功能 | API选择 | 说明 |
|------|--------|------|
| Speech-to-Text | Whisper API (OpenAI) / Google Cloud Speech | Whisper免费额度有限，可用Google Cloud免费层 |
| 文本处理 | Claude API (Anthropic) / OpenAI GPT | 申请免费额度或使用开源模型 |
| 备选方案 | 本地模型（Whisper-CPP、LLaMA） | 降低API成本 |

---

## 非功能需求

### 性能
- 录音启动时间 < 1秒
- 语音识别延迟 < 5秒（依赖API）
- UI响应时间 < 500ms

### 可靠性
- 异常录音自动保存
- 网络断线时本地缓存请求
- 错误重试机制

### 可扩展性
- 后端API与前端解耦
- 支持插件化AI功能
- 支持多API Provider切换

### 安全性
- API密钥加密存储
- 本地数据库加密（可选）
- 隐私模式（不上传原始音频到云，仅保留本地）

## 第一版MVP范围

### 必做功能
1. **基础录音**：录制、保存、播放
2. **语音识别**：一键转文字（使用免费API）
3. **文本管理**：查看、编辑、删除
4. **基本AI处理**：生成摘要、提取关键词
5. **UI主面板**：录音按钮、文本显示、历史列表

### 暂不做
- 云同步、多设备同步
- 高级搜索与过滤
- 合作编辑
- 复杂插件系统

## 已知风险与应对

| 风险 | 影响 | 应对方案 |
|------|------|--------|
| 免费API额度限制 | 功能受限 | 预先调研各API免费额度，支持多Provider切换 |
| 音频编码兼容性 | 识别失败 | 统一音频格式（PCM/WAV），格式转换库支持 |
| 网络延迟 | 用户体验差 | 本地缓存、异步处理、进度反馈 |
| 跨平台兼容性 | 后续维护困难 | Electron框架保证，提前设计分离接口 |
