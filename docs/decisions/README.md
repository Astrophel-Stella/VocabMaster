# 架构决策记录(ADR)

本目录用 **ADR(Architecture Decision Record)** 结构化沉淀关键决策——服务"人类决策"支柱:
让每个重要取舍**可追溯、有理由、能喂回给 AI 当上下文**。

## 约定

- 一个决策一个文件:`NNNN-短标题.md`(编号递增)。
- 决策一旦被推翻,不删除,改状态为「已废弃」并链接到取代它的新 ADR。
- 做架构级/依赖级取舍时,**先写 ADR 再实现**(见 `CLAUDE.md` §4)。

## 模板

```markdown
# NNNN. 决策标题

- 状态:提议 / 已采纳 / 已废弃(被 NNNN 取代)
- 日期:YYYY-MM-DD

## 背景
要解决什么问题?有哪些约束?

## 决策
我们决定做什么。

## 理由
为什么这样选,而不是其他方案。

## 后果
带来的好处 + 代价 + 需要注意的地方。
```
