## 背景与目标

词库选择页是登录后的首屏。原样式为朴素列表，缺乏品牌感与信息层次。
本需求在**不破坏既有交互契约**的前提下升级视觉：Hero 区、总览统计、主题化词库卡片。

## 验收标准

### 正常流程
```
Given 用户已登录且词库加载成功
When  进入词库选择页
Then  展示标题 "选择词库" 与 Hero 徽章/副标题
And   展示三项总览统计：词库数 / 收录单词总数（千分位）/ 许可证(MIT)
And   每个词库渲染为一个卡片按钮，含名称(<h3>)、描述、"X 词" 词数
And   点击任一卡片调用 selectWordBank 并进入学习页
```

### 异常流程
```
Given 词库接口加载中
When  进入页面
Then  展示加载动画(.animate-spin)与文案"加载词库中"，且不渲染任何词库按钮

Given 词库接口返回错误
When  进入页面
Then  展示错误容器(.bg-red-50 border border-red-200)与错误信息，且不渲染词库按钮

Given 词库列表为空
When  进入页面
Then  不渲染任何词库按钮（空状态非按钮）
```

## 技术设计

- **组件**：`frontend/src/components/WordBankSelect.tsx`
  - Hero 徽章 + 标题"选择词库" + 副标题。
  - 总览统计：词库数、`totalWords.toLocaleString()`、MIT。
  - `CARD_THEMES` 主题数组，按索引循环上色；卡片为 `<button>`，含 `aria-label` 与 `focus-visible:ring-2`（可访问性）。
- **保持的交互契约（供既有测试稳定）**：
  - 标题文案 `选择词库`；每个词库一个 `<button>`，内含 `<h3>{name}` 与 `{total_words} 词`。
  - 加载/错误/空三态选择器与文案不变。
- **配置一致性**：纯前端视觉改动，无硬编码 host/URL。

## 测试证据

- E2E（生产配置）：`word-bank.spec.ts` —— 4 卡片、名称 heading、词数、点击导航、加载/错误态。
